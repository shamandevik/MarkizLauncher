Вопросы.

Это бесплатно?

Да. Без рекламы и постороннего софта в установщике.

Нужен купленный Minecraft?

Нет, можно играть по нику. С лицензией — вход через окно Microsoft, пароль лаунчер не видит.

Java ставить нужно?

Нет, лаунчер скачает подходящую версию сам — отдельно для каждой сборки.

Антивирус ругается — что делать?

Скачивайте только из Releases этого репозитория. Проверьте файл на VirusTotal и сравните хеш с релизом.

Что-то не работает?

Заведите issue в репозитории и приложите logs/launcher-latest.log из папки сборки.

Это тот же Millida Launcher?

Markiz — форк Millida Launcher: тот же движок, своё имя и свои иконки. Исходный проект под GPL-3.0, форк легален, бренд и сервисы оригинала под лицензию не попадают.
